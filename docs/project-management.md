# Project Management

## Outils de collaboration

| Outil | Usage |
|-------|-------|
| **Trello** | Suivi des tâches, assignations, priorités |
| **GitHub** | Versioning, pull requests, code review, CI |
| **Discord** | Communication quotidienne de l'équipe |

## Board Trello

Lien : (lien d invitation retire)

Le board contient :
- Les tâches découpées par fonctionnalité
- Les assignations par membre de l'équipe

## Workflow Git

- Chaque fonctionnalité fait l'objet de commits réguliers et descriptifs
- Les branches sont mergées sur `main`
- Le CI GitHub Actions valide après le push

## Communication

L'équipe se synchronise quotidiennement via Discord pour :
- Le point d'avancement des tâches
- Les décisions techniques
- La résolution des blocages
